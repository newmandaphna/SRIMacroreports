Offline backup

Replit keeps point-in-time recovery for a rolling window only, with no snapshots and no export button. This downloads a full pg_dump archive of the database, so a copy can exist somewhere Replit is not. It contains everything, patient names included: the download is recorded in the audit log as a PHI export, and the file belongs on an encrypted drive, not in a downloads folder. Restore with: pg_restore --clean --if-exists --no-owner -d <connection-url> <file>
